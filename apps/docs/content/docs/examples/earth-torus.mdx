## Overview

This example uses `createTorusTopology` for an Earth-area torus with a roughly 3:1 ratio between major and minor radii. It shares procedural elevation and altitude-aware cameras with the [Earth-scale planet](/examples/earth-planet).

The topology distributes roots along the ring and tube. The runtime uses tile-relative vertex construction and a common query API; source evaluation on large absolute coordinates still has f32 limits. Ground-level precision depends on source coordinates, mesh resolution, storage, and rendering paths. See [runtime precision limits](/docs/core/runtime) and [Terrain Gym](/docs/terrain-gym).
