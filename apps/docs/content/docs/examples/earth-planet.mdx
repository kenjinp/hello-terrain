## Overview

This example uses a cube sphere with radius **6,371,007.2 metres**, procedural elevation, and altitude-aware orbit and fly cameras. It exercises refinement from orbit toward ground level.

The runtime constructs vertices relative to tile anchors and preserves small offsets through camera-relative placement. This removes the previous absolute-position construction path. Elevation callbacks still use ordinary TSL: arithmetic on planet-sized `worldPosition` values remains subject to f32 precision. Increasing `maxLevel` alone does not guarantee finer source detail.

Use the controls to compare LOD strategies and inspect tile density. See [runtime precision limits](/docs/core/runtime) and the [Terrain Gym](/docs/terrain-gym) for measured fixtures and remaining coverage limits.
