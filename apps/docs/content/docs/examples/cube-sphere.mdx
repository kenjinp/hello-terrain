## Overview

This example demonstrates the `createCubeSphereSurface` API, which maps a quadtree across 6 cube faces and projects them onto a sphere.

Each cube face is its own quadtree space. As the camera approaches the sphere, nearby tiles subdivide to high LOD while far-side tiles remain coarse. Cross-face neighbors are correctly resolved so seam continuity is maintained across all 6 faces.

### How it works

1. **6-face quadtree** — each face covers one side of a unit cube, giving 6 independent root tiles.
2. **Sphere projection** — tile vertices are normalized from cube coordinates to the sphere surface, then scaled by the radius.
3. **Face-edge neighbors** — `neighborSameLevel` handles cross-face edges with proper coordinate remapping, enabling seamless LOD balancing across the entire sphere.
4. **Radial elevation** — the elevation function displaces vertices outward along the surface normal (radial direction) rather than along a fixed Y axis.

### Controls

| Control | Description |
|:--|:--|
| **radius** | Sphere radius in world units (also used as the root tile size) |
| **max level** | Maximum quadtree subdivision depth |
| **max nodes** | Total node budget across all 6 faces |
| **elevation scale** | Scale applied to the radial elevation function |
| **skirt scale** | Skirt inset distance to hide tile seams |
| **wireframe** | Toggle wireframe to visualize per-tile coloring |
