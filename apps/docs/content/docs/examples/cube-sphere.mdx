## Overview

This example uses `createCubeSphereTopology` to refine six cube-face charts around a sphere. The projection displaces the spherical datum along its radial direction. The runtime publishes geometry and query snapshots; applications sample every topology through the same query API.

Face connectivity does not by itself guarantee seamless source maps or mixed-LOD geometry. See [topology](/docs/core/topology) and [precision validation](/docs/terrain-gym).
