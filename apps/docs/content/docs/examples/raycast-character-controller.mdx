## Overview

This example grounds a third-person character using the runtime binding. `binding.sampleWorld(position)` returns elevation, position, and normal with availability metadata. `binding.raycastWorld({ origin, direction }, options)` searches the sampled surface and returns `hit` or `incomplete`.

Movement must handle missing coverage and pending CPU snapshots. A rendered terrain is not sufficient evidence that a synchronous query is available. See [terrain queries](/docs/core/query/terrain-query) and [raycasting](/docs/core/query/raycasting).
