## FBM Terrain

This scene shows the basic `useTerrain()` plus `Terrain` flow:

- create a terrain handle with `useTerrain()`
- pass it into `Terrain`
- render the surface with a node material using `positionNode`

  <FbmTerrainScene />
</div>

## Character Controller

This scene shows the shared-handle pattern:

- create one terrain handle
- wrap siblings in `TerrainProvider`
- let the character controller and camera read `terrain.runtime`
- use `terrain.ready` to gate terrain-dependent behavior

  <RaycastCharacterControllerScene />
</div>
