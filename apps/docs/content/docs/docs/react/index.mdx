---
title: React Overview
description: React Three Fiber integration with the terrain runtime
---

`@hello-terrain/react` owns a lifecycle lease on the same runtime used by vanilla Three. `Terrain` renders its published mesh; `useTerrain` exposes its controller and subscribed status; `TerrainProvider` shares a handle.

```tsx
<Terrain rootSize={128} elevation={elevation} elevationRange={{ min: -1, max: 1 }}>
  {({ positionNode }) => <meshStandardNodeMaterial positionNode={positionNode} />}
</Terrain>
```

Use `useTerrain()` when controllers or tools need the handle. The simple API does not require task arrays or duplicated mesh capacities. Pass `positionNode` to your material and compose direct elevation, slope and mapped textures through `materialContext`. Material identity is preserved across node updates.

Use per-sample availability and render/query revisions for gameplay. See [useTerrain](/docs/react/use-terrain), [queries](/docs/core/runtime), and [material authoring](/docs/core/nodes/materials).
