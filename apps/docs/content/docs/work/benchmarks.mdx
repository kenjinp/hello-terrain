title: Benchmarks
description: Reproduce the work graph hot-loop benchmarks
---

Run `pnpm bench:work:docs` from the repository root to measure the current checkout and regenerate this page with local results.

The suite compares clean runs, parameter changes, wide independent graphs, and deep dependency chains. Results depend on the runtime, hardware, graph size, and task work. These graph scheduling measurements do not measure terrain GPU production, rendering, or readback latency.

For terrain correctness and diagnostic workloads, use [Terrain Gym](/docs/terrain-gym).
