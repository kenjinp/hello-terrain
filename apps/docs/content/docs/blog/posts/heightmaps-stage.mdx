## Heightmaps

We should allow users to pass in their own elavation function

in most cases this might be a heightmap, so we can provide a heightmap Fn out of the box

Otherwise they should be able to use the elevationFn to add noise or whatever. 

the fn will provide nodes as input so they can figure out what vertex and tile they operate on
